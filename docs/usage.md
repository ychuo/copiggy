# Usage

Copy normally with **⌘C**. Open Copiggy from its menu-bar icon or with **⌃⌥⇧Space** to browse the history. Selecting, searching and previewing a record leave the system clipboard unchanged.

Press **Return** or double-click a card to copy the selected content and close the panel. Without an explicit format choice, Return copies the exact original. If you explicitly choose a supported format, Return copies that format instead. Paste in your destination using **⌘V**; Copiggy does not paste automatically.

## Shortcuts

| Action | Shortcut or control |
| --- | --- |
| Show / hide the panel | ⌃⌥⇧Space or menu-bar icon |
| Search | ⌘F or search button |
| Navigate cards | ← / → |
| First / last card in the current list | ⌘← / ⌘→ |
| Return from search to cards | ↓ |
| Preview selected card | Space or ⌘Y |
| Copy selected content / chosen format | Return |
| Pin / unpin | ⌘P or pin control |
| Delete selected record | ⌘⌫ or preview delete control |
| Close preview / search / panel | Esc |
| Copy with source-app protection | ⌃⌘C, while protection is enabled |

Arrow keys, including ⌘← / ⌘→, retain normal text-editing behavior while the search field has focus. The top pin button switches between all history and pinned items. Right-click the menu-bar icon for recording, history retention, appearance, language, phone region and quit options. Menu items show icons and native shortcuts. Only protection updates and errors appear beside the menu-bar icon; hover and routine successes stay quiet.

When history is empty, Copiggy's pig occasionally blinks while three short lines appear one by one on its clipboard, pause, then fade. The empty pinned list shows the same pig pressing a pin into a note, with a quiet rest between gestures. Both stay still when macOS Reduce Motion is enabled. The menu-bar pig holds a small clipboard and gains a shield when Paste Guard is active.

## Content previews

- **Text:** read the full saved text.
- **JSON:** choose Format, then Return or Copy result to copy the draft. Compare with Original or choose Copy original to keep the captured representation. Cancel or navigate away to discard the draft. Neither copying a result nor cancelling adds a history record.
- **Markdown:** a warm-white document card with a coral left edge and its own M↓ symbol. Cards show up to three actual blocks; a leading heading with a list emphasizes the heading and first list entries. The 600 × 460 preview switches between Reading and the exact Source, with character count and protection fixed below the paper. Reading supports headings, lists, quotes, emphasis, code, task indicators and tables; wide tables scroll horizontally. Source preserves indentation and long lines with scrolling in both directions. Links are reading text; images show their alt text and embedded HTML remains literal. Neither mode fetches images or executes HTML, and both copy the complete original Markdown.
- **Images:** edge-to-edge image cards with small glass metadata labels. Enlarge, zoom or fit the image in preview.
- **Links:** complete HTTP(S) addresses, bare domains such as `example.com/page`, and standalone `[title](web link)` values use the website card. Explicit unrestricted public web links use matching copied metadata or fetch a title/cover when the card comes into view. Bare domains derive HTTPS for opening but do not automatically fetch metadata/icons. Web links open in the 720 × 500 page preview, with navigation, refresh/stop and Open in browser. Page / QR switches to a compact 520 × 500 QR preview and back to the same open webpage. QR shows only the code and scanning caption on opaque warm paper, with the exact saved source beside Copy below; website icons, domains and page navigation are omitted from the QR toolbar. QR always uses the saved destination rather than a later webpage redirect. Default copying preserves the original text, including a bare domain or Markdown wrapper.
- **App scheme:** an independent card for destinations such as `aweme://video/123`, `sslocal://route` and `[Open video](aweme://video/123)`. A cream pass sits in a peach sleeve with a centered U opening and a small top slot. It emphasizes `scheme://` above up to two lines of host/path; long parameters stay in preview. The 520 × 500 preview opens directly to a locally generated QR on opaque cream paper, with only the code and scanning caption and no scheme heading or icon. QR / Link switches between the code and exact saved source; Copy and protection stay below the paper. Open in app is explicit. This type never creates a webpage view or fetches an icon, title or cover, and both display modes copy the complete original record.
- **Email:** a blue envelope card with the address split into name and domain. Mail opens a draft in the registered mail app.
- **Phone:** a mint card with the number and a subtle dial pad. Choose Dialing number, then Return to copy the normalized number. Original number restores exact-original copying. Call opens the registered phone handler.
- **Coordinates:** a map card with a marker. Preview zooms the map and shows the coordinate pair; Maps opens the location externally.
- **Date:** an integrated calendar card with a compact coral month band. Preview shows the date, weekday and time. Calendar opens an importable event file; the calendar app handles confirmation.
- **Timestamp:** a dark counter card with a readable date. Choose seconds or milliseconds, then Return to copy that unit. Local/UTC changes only the date explanation. Copying seconds from milliseconds drops the subsecond digits; the saved original keeps them.
- **Color:** the color fills the card. Choose HEX, RGB or HSL, then Return to copy that representation. Transparent colors appear over a checkerboard.
- **File path:** a folder card with the filename and parent directory. Finder reveals the local item without executing it. Copying a file or folder in Finder produces the same path preview as copying its full path as text. Return or Copy in Copiggy writes the full path as plain text. Multiple selections become one path per line, with the same preview as directly copied multiline path text. There is no separate file-copy mode. Capturing or previewing these paths never reads file contents, downloads cloud placeholders or writes the system clipboard. Finder’s own Cmd+C followed directly by Cmd+V still pastes files; using a Copiggy record replaces the clipboard with path text.
- **Verification code:** a lavender card with all digits immediately visible.
- **Token:** a dark card with three rows showing the first and last six characters and masking the middle, plus a format label such as JWT. Reveal shows the full saved value.
- **Private key:** an ivory sealed-paper card with four rows showing the first and last six characters of its encoded payload and masking the middle. Reveal shows the full saved value.

Choosing a format changes the next explicit copy, not the clipboard immediately. Copied variants are plain text, keep the saved record’s protection scope, and never replace the original or add another history item. Closing the preview or navigating to another record resets the choice; reopen and press Return without choosing a format to copy the exact original (or the saved paths for a Finder selection). Reveal, zoom, QR and Markdown Reading/Source do not change what is copied. Display modes reset on closing/navigation: App links return to QR, web links to their page, and Markdown to Reading. Token and private-key previews return to the abbreviated value when closed or changed. Masking is separate from Paste Guard: source-app restrictions appear only when the record actually has them.

Recognition matches whole values conservatively. It supports web/app links, validated bare-domain syntax, structured Markdown, complete mailboxes with optional display names or simple `mailto:` wrappers, region-aware phone numbers, decimal or directional coordinates, year-first dates, Unix timestamps within 2000–2099 with optional `s`/`ms` units, HEX/RGB/HSL/HWB colors, local absolute or `~/` paths with optional quotes, labeled verification codes, known token prefixes/JWTs with optional Bearer wrappers, and complete PEM private keys. URI-only clipboard data can supply one explicit web/app link or a multiline list. Ambiguous values remain ordinary text; bare four/six-digit numbers are not assumed to be verification codes. Restored text records are recognized again without altering their saved content; older App destinations saved as Links acquire the independent App scheme presentation while keeping their identity, source and protection. See [Content recognition rules](recognition.md) for all 16 types, exact matching order, accepted formats and limits.

Bare-domain recognition uses IDNA and a bundled public-suffix list without contacting the domain. Examples such as `www.example.com` and `bücher.de/page` work; bare IP addresses, single-label hosts, unknown suffixes and common ambiguous file endings such as `.md`, `.zip`, `.mov`, `.sh` and `.rs` stay text unless given an explicit HTTP(S) address. App links require a complete `scheme://` route and open only after an explicit action; `javascript:`, `data:` and `vbscript:` are not App links. Email, phone and local file URIs retain their specialized cards. A phone scanning an App QR still needs a compatible application installed.

Markdown requires clear structure, not just a `#`, `*` or `-`. Headings, multi-item lists, letter-containing quotes, closed nonempty code fences, tables, task markers, images/links and bold text qualify; two inline formatting spans also suffice. Documents are limited to 64 KiB, 2,048 LF characters, 4,096 syntax nodes and nesting depth 32; tables allow 16 columns and 256 rows including the header. Documents outside these bounds remain full ordinary text. QR targets are limited to 2,048 UTF-8 bytes and 157 modules per side including the quiet zone, so some shorter complex targets also exceed the readable-symbol limit and show an error.

Coordinates accept decimal pairs such as `37.428230, -122.168861`. Longitude may come first when its range makes the order clear; when both values fit either axis, latitude stays first. Explicit N/S/E/W directions allow either order, including `37.428230N, 122.168861W`, `37°25.6938′N 122°10.13166′W` and `37°25′41.628″N 122°10′7.8996″W`. Dates accept a four-digit year followed by month/day with matching `-`, `/` or `.` separators, such as `2026/10/3`, optionally followed by a time. Dates with explicit time zones retain RFC 3339 syntax; ambiguous `03/04/2026` stays text. HSL/HWB hue supports degrees, `turn`, `rad` and `grad`, including `hsl(0.5turn 100% 50%)`. These interpretations never rewrite the original copied text.

Phone region defaults to the macOS region, independently of interface language and time zone. Select a different region from the menu-bar menu for new captures. Explicit international prefixes take precedence; local Chinese mobile numbers, Japanese national numbers and other supported numbering plans are validated with bundled offline libphonenumber metadata. Full-width digits, common spacing and hyphens, `tel:` values and numeric extensions are supported. A bare value that matches both a phone number and a timestamp remains text. Number-plan validation does not establish whether a number is currently assigned or reachable.

Phone preview shows a bundled flag image and a localized country or region name from the parsed number. When offline numbering metadata provides a more detailed city, province or state, preview shows it below the country. Localized place names are preferred, with English as the fallback when a detailed translation is unavailable; country-only results are not repeated. These descriptions identify the number's assigned numbering area, not the person's nationality or current location. Unknown regions and international service numbers have no flag. Flags and place descriptions are local, with no emoji or network requests; detailed lookups start only when opening preview.

Each record saves its resolved region. Changing the preference does not reinterpret existing records or exact repeats. Older history receives a region once on upgrade, preserving already recognized phones' interpretation and using the current region otherwise. Call uses the validated international form and preserves a numeric extension; Dialing preserves the national dialing digits where applicable, with `;ext=` for an extension. Original number always retains the exact captured text. Finder records retain their captured representations for history integrity, but every copy from Copiggy derives only path text from the saved file references and inherits their protection scope. Older file cards are restored into the same path presentation.

Exact repeated content with the same protection scope updates the existing record's time and moves it to the front. Records with different protection scopes stay separate. Deleting a history record does not clear the system clipboard or remove protection already bound to its current contents.

## Protected copy

Enable the shield toggle and grant macOS Accessibility permission if requested. In the source application, select content and press **⌃⌘C**. Copiggy performs that copy and binds it to the source application. The source icon gains a lock badge; a brief menu-bar message confirms the restriction.

While the guard is active, standard **⌘V** and **⌘⌥⇧V** are blocked in other applications. Ordinary **⌘C** does not inherit a previous copy's restriction. The menu-bar icon and shield toggle show the current guard state.

This protects against accidental keyboard paste. It does not prevent other applications from reading the clipboard, menu or context-menu paste, custom paste shortcuts, or pasting into the wrong conversation inside the same application. Protection stops when the app quits or its native listener loses permission.

## Storage and network behavior

History is saved locally in `~/Library/Application Support/Copiggy/history.json`, including its exact clipboard content, source, time, pin state and allowed applications. Existing `pinned.json` records are migrated on first use of this version. The previous pin file remains as a migration backup and is not read again after the unified history file exists.

Use the menu-bar **Keep History** setting to choose **1 day**, **7 days**, **30 days** (default) or **Forever**. Pin records to exclude them from age expiry. Up to 100 ordinary records and 100 pins are kept, with a shared 64 MiB content budget; “Forever” removes the age limit, not these size limits. Deletions, unpins and recopy timestamps are saved. Shortening the retention period removes expired ordinary records. Expiry runs at startup, when opening the panel and periodically while running, including while recording is paused.

Language, explicit light/dark choices, phone region, recording pause, the Paste Guard preference and retention are saved together in `preferences.json`. Changing one setting preserves the others. Older settings files default to recording on, Paste Guard requested on and 30-day retention; a missing theme uses the system appearance until one is chosen. On restart, Paste Guard is enabled only if requested and macOS permission allows it; the shield always shows the actual listener state.

Restoring history never writes the system clipboard or restores an old clipboard revision's protection. Copying a saved restricted item binds its saved allowed applications to the new write. Search, selection, open previews, format choices and unfinished enhancements are not restored.

JSON formatting, Markdown reading, QR generation and content recognition run locally. QR generation happens only inside an opened preview: by default for App links, or after choosing QR for web links. It never runs during capture or card display, and never sends the address to a QR service. Markdown does not fetch remote images, open inline links or execute HTML. Masking does not encrypt stored history; credentials retain the same history retention and deletion controls as other records.

Link title and cover retrieval starts lazily for visible or nearby unrestricted explicit public HTTP(S) cards, never during clipboard capture. It requests the saved destination including its path and query, strips the fragment, and reads Open Graph or Twitter metadata and its cover image. Protected records, private/local addresses, inferred bare domains and App links are not fetched. These requests use no browser cookies, authentication or referrers, and execute no scripts. Website icons keep a separate origin-only retrieval path that omits the copied path and query and also excludes inferred domains/App links. Matching metadata already included in copied HTML can be used locally for inferred domains.

Link metadata and map snapshots share a 24-entry, 24 MiB memory cache. Link retrieval uses at most three workers; covers expire after six hours, and failed or coverless results after ten minutes. Hiding the panel or quitting cancels pending work. This cache is not saved to disk.

Opening a webpage preview explicitly loads the saved destination, including its path and parameters, in Copiggy's WebKit session. Bare domains receive HTTPS and standalone Markdown links use their destination; the saved source remains unchanged. Unlike metadata retrieval, this uses WebKit's normal persistent website data store, including its cookies; it is not private browsing. App-link previews never create a webpage view. Choosing QR does not create one either; it hides an already open page and keeps that same view for returning to Page while the record, saved destination and popover host remain the same. Switching modes does not reload the page, so its current navigation and scroll position remain available. A hidden page is not paused and may continue loading or running its own scripts. Closing the preview, changing records, hiding the panel or quitting releases the page view.

Visible unrestricted coordinates request system map snapshots from Apple Maps. This sends the coordinate region, not your device's location; it does not request location permission. Protected coordinates never request a snapshot automatically. Map images stay in a bounded memory cache; unavailable maps fall back to the coordinates. Explicit Mail, Call and Maps actions pass their displayed value to the corresponding handler. There are no cloud AI calls or bulk history uploads.
