  预览选择与当前剪贴板标记仍分离。范围锁、当前标记和保护状态均有无障碍文本。

## 发现与修复

1. **P2，首轮字体与图标偏小。** 对照 `comparison-before.png`，
   实现信息层级比参考细弱。将列表正文改为 17 px、辅助文字 13.5 px、
   JSON 14 px、来源图标 41 px，并增加标题栏高度和玻璃白色基底。
   `comparison-final.png` 显示修复后状态。
2. **P2，键盘焦点与选择可能不一致。** Tab 到另一历史行后回车原先可能使用旧选择。
   现在历史行回车与点击一致，先预览该行并回到搜索焦点，再按回车明确选用。
   浏览器复测了 JSON 已选中 → 图片行 Enter → 图片预览 → 再 Enter 选用。
3. **P2，多行 JSON 历史摘要只有左花括号。** 改为压平换行的内容摘要，
   完整格式仍保留在详情中；增强结果历史可识别。
4. **P2，图片容器过高且实际图像圆角不稳定。** 使用实际图片元素的圆角与等比适配，
   最大预览高度 205 px。修复后的 `qa/image.png` 保留完整 4:3 图像，
   主动作完整可见，切换图片时窗口高度仅有少量变化。

早期个别直接截图捕获到宽度动画中间帧，或比 DOM 晚一帧的内容。
这些捕获不作为验收依据；最终 JSON / 图片均通过独立的屏幕观察重新捕获，
并在 `comparison-final.png` 中确认状态相符。

## 有意保留的差异

- 概念图自行增加了红黄绿窗口按钮。网页原型改为应用名和一个收起按钮，
  适配临时工具面板，不模拟关闭应用、最小化或全屏。
- 概念图图片呈宽幅裁切却标 4:3 尺寸；实现以“不裁切内容”为准，
  显示完整 1448 × 1086 图像，因此预览左右有留白。它是同方向的新生成照片，
  不是概念图里那张照片的像素复刻。
- TextEdit 图标以本机真实资源为准。额外读取系统合成图标仍得到纸张外观，
  没有凭概念图手画一枚带笔图标。
- JSON 的列表和详情保持相同有效数据，包含 version；概念图各处数据不完全一致。
- 原型材质为网页模拟，MyGo 原生 Liquid Glass 渲染未在此验收。
