# Copiggy 面板交互原型

当前方向是**不同内容显示不同卡片，预览通过快捷键唤起浮层**。
顶部搜索默认收为与预览眼睛同款的圆形图标按钮，中间是横向的 204 × 204px 正方形卡片，
防误贴开关与单键提示位于底部。点击搜索或按 `⌘F` 才展开输入框。
不再采用纵向列表加固定右侧详情；用户已明确允许调整布局和交互。
产品规则见 [面板设计](../panel-design-v2.md)。

保留浅色、深色玻璃外壳与克制的扁平控件。卡片根据文本、JSON、图片、链接的
内容特征呈现，类型文字改为带悬停说明和无障碍名称的 Phosphor 图标。
来源应用是卡片右上角的小图标；
应用范围用图标右上角的小锁表示。内容预览仍统一为上方正文、下方信息和相关操作，
但按需作为非模态浮层出现，不占据常驻右栏。浮层下缘的小尖角与主体共用一块玻璃背景，
透明度、模糊和外轮廓连续一致，根部没有拼接线。小尖角指向选中卡片，
切换卡片、滚动或调整窗口时跟随位置；浮层贴近屏幕边缘时，尖角仍单独调整方向。
浮层贴近所选卡片上边缘：底边距卡片 22px，16px 尖角后仅留 6px 空隙。
因此预览可以覆盖上方搜索栏；按 `⌘F` 会收起预览并展开、聚焦搜索。

原型只使用示例数据，不读取或修改系统剪贴板。“取用”只更新网页内的演示状态。
它不替代 [MyGo 原生验证](../mygo-feasibility-2026-10-20.md)，
本轮不重建或修改已经验证的原生应用。浏览器检查见 [设计验收](final-design-qa.md)。

## 当前交互

- 初始打开或重新唤起面板时聚焦所选卡片，搜索保持收起，不自动进入搜索。
- 单击卡片仅选择；不会改变当前内容，也不会自动打开预览。
- 点击圆形搜索按钮或按 `⌘F` 展开并聚焦输入框。
- `←` / `→` 在卡片之间导航；搜索框内按 `↓` 进入所选或第一张可见卡片。
- 卡片聚焦时按 `Space`，或点击预览图标，打开/收起内容浮层。
  搜索中的空格仍是输入；`⌘Y` 可以从搜索唤起已选记录的预览。
- 卡片上 `Enter` 取用保存项；双击同样取用卡片原项，不确认浮层里的草稿。
  浮层中 `Enter` 取用当前看到的内容：原文对照时取用原文，结果视图时确认草稿。
  焦点在格式化、对比等按钮上时，`Enter` / `Space` 执行按钮动作。
- `Esc` 每次只关闭最上层；关闭内容浮层会取消未采用草稿与处理任务，
  保留搜索和选择，并回焦所选卡片。图片放大关闭后回到内容预览。
  没有预览层时，有搜索词先清空；空输入框再按 `Esc` 收起搜索并回到卡片；
  搜索已收起时才关闭面板。
- 搜索可匹配内容、类型、来源应用。筛掉当前选择时高亮首个匹配项并关闭预览，
  不改变当前剪贴板；没有匹配记录时清除选择，不打开空浮层。
- 切换记录、关闭预览或面板都会使旧处理回调失效，避免迟到结果串到另一记录。

## 卡片与内容增强

| 内容 / 类型图标 | 历史卡片 | 浮层 |
|---|---|---|
| 文本 / `TextT` | 可读正文摘要，保留主要内容层级 | 完整正文、字符数及必要范围；无处理按钮 |
| JSON / `BracketsCurly` | 代码呈现，不自动改变原内容 | 原文、字符数、范围和格式化图标；显式格式化后才生成草稿 |
| 图片 / `Image` | 图片缩略图 | 等比内容预览、实际像素尺寸、PNG 格式和放大入口 |
| 链接 / `LinkSimple` | 地址与域名帮助识别 | 完整地址与字符数；无处理按钮，不假装已抓取网页元数据 |

JSON 格式化实际执行本地解析和字符串处理。草稿可以对照原文、返回结果或放弃；
确认后才新增结果记录并更新网页内当前内容。原文保留，结果继承原项的来源与应用范围；
继承说明只放在范围行的悬停提示中，不在可见范围后重复追加“继承原文”。
查看原文时，浮层提示改为“取用原文”，回车取用保存的原文并放弃未采用草稿；
返回结果视图时提示“取用结果”，回车才确认派生结果，保持所见即所得。
若处理期间当前内容发生变化，保留“取用将替换它”的提示，与原文/结果视图一致。
图片没有 OCR、压缩等尚未接入的处理，AI 也未接入。

## 视觉与状态

- 不保留 Copiggy 标题、红绿灯、顶部关闭工具栏或“设为当前”按钮。
- 不用内部分割线组织区域；以留白、字体、卡片表面、选中态与必要焦点轮廓区分。
  一个按键一个键帽，图标有悬停说明及无障碍名称。
- 浅色与深色使用同一结构和行为，玻璃外壳透出背景颜色；文字与图标保持清楚。
  不给搜索、键帽、圆形按钮重复添加控件高光、内阴影或多层胶囊。
- 当前剪贴板、卡片选中、应用范围和防误贴运行状态分别表达。
  来源小锁不能代替防误贴是否生效的提示。
- 左下防误贴开关直接切换，盾牌勾/斜线盾牌、滑块位置与颜色一起表达状态。
  关闭时开关旁只显示“已关闭”，受限项的小锁为琥珀色。
  浮层范围行统一为暖色的“仅限文本编辑 · 未生效”，详细说明放在悬停提示中；
  不再显示单独的大警告条，范围继承逻辑保持不变。
- 面板外的浅色/深色切换只改外观，保留搜索、选择、浮层、草稿与守卫状态。
  `localStorage` 保存所选主题，首次使用浅色；重置示例不重置主题。

## 保护复制演示

页面下方“防误贴演示”展开独立模拟区：

1. 模拟 `⌃⌘C` 创建来源为文本编辑、范围仅限文本编辑的示例记录。
2. 选择模拟目标应用，再点击模拟 `⌘V`。
3. 守卫开启时，同源允许、跨应用受限；关闭时应用范围暂不生效。
4. 选中受限 JSON，打开预览、格式化并确认，继续检查派生结果的范围继承。

以上不接管系统快捷键，不读取真实前台应用，不请求 macOS 权限。
网页守卫状态不能说明机器上的原生防误贴是否运行。

## 运行与范围

在本目录执行：

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

默认地址为 [127.0.0.1:4173](http://127.0.0.1:4173)。重置或刷新恢复内存示例状态，
主题偏好单独保留。不包含原生后端、系统剪贴板监听/写回、真实跨应用按键拦截、
AI 服务或历史持久化。

系统减少透明度或浏览器不支持背景模糊时，回退到对应主题的不透明表面。
正式原生材质、复杂背景下的可读性、焦点恢复及系统偏好响应仍需单独实现和验证。
底层 PNG 读写的既有验证不等于原生图片历史、图片保护复制或本原型全部交互已验收。
