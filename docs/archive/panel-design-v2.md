# Copiggy 面板设计 v2

更新日期：2026-10-21。

当前方向是**横向内容卡片＋快捷键唤起的预览浮层**。用户希望借鉴 Paste 参考图中
“不同内容有不同呈现”的卡片，以及独立浮层的轻量感，并明确允许调整布局和交互。
这替代此前连续纵向列表、选择即展开右侧详情、固定左右分栏的要求。
浅色与深色的玻璃外壳、克制的扁平控件、无内部分割线和少文字原则继续保留。

[网页交互原型](prototype-qa/prototype-readme.md) 用示例数据检查视觉和交互。
下文仍包含待落地的原生能力，不能把网页状态视为系统集成已完成。
技术行为依据见 [产品流程](product-flow-v1.md) 和 [MyGo 技术验证](mygo-feasibility-2026-10-20.md)。

## 当前结构

只有一个日常操作面板：顶部是收起的圆形搜索按钮和同款预览眼睛按钮，
中间是横向 204 × 204px 正方形卡片，底部防误贴开关与快捷键提示。
点击搜索按钮或按 `⌘F` 才展开并聚焦输入框；初始打开或重新唤起面板时聚焦所选卡片。
不显示 Copiggy 标题、红绿灯、冗余顶部工具栏，不预留空白详情栏。
记录数量增加时横向浏览，键盘导航使所选卡片保持可见；窄窗口保留卡片结构，
不把内容硬压缩成不可读的多列网格。

单击只选择卡片。需要读完整内容或增强时，按空格或点击预览图标唤起非模态浮层；
浮层与历史保持上下文关联，不扩大主面板来腾出右栏。上方是内容，
下方是固定的信息与适用操作，四类内容采用相同骨架。纯文本没有为了填满布局而添加的操作区。
浮层下缘添加小尖角，指向选中的正方形卡片，以表达预览与记录的对应关系。

卡片依据内容变化，而不是只替换类型标签：

| 类型 / Phosphor 图标 | 卡片呈现 | 浮层内容及操作 |
|---|---|---|
| 文本 / `TextT` | 可读正文摘要，保留内容层级和必要换行 | 完整正文、字符数与必要范围，无处理按钮 |
| JSON / `BracketsCurly` | 代码排版与结构帮助识别 | 默认显示原文；底部字符数、范围和格式化图标，显式触发后生成草稿 |
| 图片 / `Image` | 图片缩略图成为主体 | 等比预览；底部实际像素尺寸、PNG 格式和放大入口 |
| 链接 / `LinkSimple` | 地址与域名帮助识别 | 完整地址与字符数，无处理按钮；不假装已抓取页面标题或封面 |

类型以图标替代文字标签，四个图标均有 tooltip 与无障碍名称，避免仅凭图形猜测。
卡片来源应用放在右上角，使用小图标而非反复显示应用名；名称通过悬停和无障碍说明可读。
受限记录在来源图标右上角叠加小锁，说明包含具体应用范围。防误贴关闭时锁为琥珀色，
提示范围未生效；浮层内只在范围行显示暖色“仅限文本编辑 · 未生效”，
详细原因放在 tooltip，不再增加大警告条。派生内容的继承说明也只放在范围 tooltip 中，
不会改变来源和范围继承规则。来源图标回答“从哪里复制”，不能代替内容本身或类型表现。
当前剪贴板另用明确标记表达，不能以选中态或锁图标代替。
来源未知时明确写“来源未知”，不猜测应用。

## 视觉规则

保留“一层玻璃外壳＋扁平控件”的材质方向：浅色雾白、深色烟灰，
背景模糊、克制外缘和柔和投影只用于承托面板与独立浮层。正文和图标保持清楚，
搜索、键帽与操作按钮不重复添加玻璃高光、内阴影或多层胶囊。
内容卡片可采用适合其类型的表面，但仍共享圆角、间距、文字与状态规范。

- 不使用装饰光斑、发光和无关渐变。留白、字体层级、卡片表面和选中态承担区分作用。
- 不用内部分割线组织内容；选中轮廓、键盘焦点反馈不受此限制。
- 使用系统无衬线字体，结构化代码使用等宽字体。辅助信息不能仅靠大幅降低不透明度来弱化。
- 浮层主体和下方尖角组成连续轮廓，共用一块玻璃背景与同一组透明度、背景模糊；
  仅沿完整外轮廓描边，根部没有矩形底边穿过，不使用独立图标或叠加的半透明三角形。
  尖角高 16px，根部与尖端采用柔和过渡。垂直定位锚定选中卡片的
  上边缘，不再锚定整个托盘上沿：浮层底边至卡片顶部为 22px，尖角之后仅留 6px 空隙。
  浮层因此贴近卡片，会覆盖上方搜索栏；按 `⌘F` 收起预览并展开、聚焦搜索。
  尖角水平位置依据选中卡片中心计算，限制在浮层左右各 42px 的安全范围内，
  避免尖角根部进入浮层圆角；
  浮层因屏幕边缘移动时，尖角仍独立跟随卡片，不固定在浮层中央。
  切换记录、滚动或窗口尺寸变化时重新定位。
- 浮层内容与底部信息采用共同对齐基准，JSON 与图片的操作位于同一下方区域。
  默认不增加重复的 JSON/Text 类型标题或单独顶部处理工具栏。
- 图标按钮有具体的 `title`、无障碍名称和可见焦点。快捷键一个键一个块。
- 选中、当前剪贴板、范围和守卫状态分别用形态与必要文字表达，不只依赖颜色。
- 浅色/深色切换在网页原型面板外；切换只改外观，保留搜索、选择、浮层、草稿和守卫状态。
  浏览器保存上次选择，首次或无有效偏好时使用浅色；重置示例也保留主题。
- 减少透明度或背景模糊不可用时，回退到对应主题的不透明表面，不改变功能与层级。
  正式原生材质、复杂背景下对比、焦点反馈与系统偏好响应仍需独立实现和验证。

## 核心模型

复制内容 → 在卡片中找到记录 → 按需打开预览或增强 → 明确取用 → 用户自行 `⌘V`。

不提供“粘贴”按钮，不固定展示“将粘贴到某应用”。搜索、选择、预览、生成增强草稿
均不改变当前剪贴板。应用范围在实际按标准 `⌘V` 时检查，不限制浏览和选用历史。

| 概念 | 含义 | 变化时机 |
|---|---|---|
| 选中记录 | 正在浏览、准备操作的卡片 | 单击、方向键；搜索排除当前项时高亮首个匹配项，空结果清空选择 |
| 当前剪贴板 | 此刻供用户自行粘贴的内容 | 明确取用、确认结果、外部成功复制 |
| 预览与草稿 | 阅读原文或检查尚未采用的增强结果 | 显式打开预览、处理、对比、取消 |
| 应用范围 | 记录及其派生内容允许通过标准快捷键粘贴的应用 | 保护复制建立，或用户明确修改 |
| 防误贴状态 | 键盘守卫此刻是否实际运行 | 开启、关闭、权限变化、监听失效 |

选择不等于当前剪贴板。范围仍保存不等于防误贴在运行。历史没有对应记录时，
不人为补造“当前”标记。取用已经是当前内容的记录不重复生成历史项。

## 键盘与浮层

| 按键或动作 | 行为 |
|---|---|
| 面板初始打开或重新唤起 | 聚焦所选卡片，搜索收起；不自动打开预览 |
| 搜索按钮 / `⌘F` | 展开搜索并聚焦输入框 |
| 搜索中的 `↓` | 进入已选或第一张可见卡片；空结果无动作 |
| 卡片中的 `←` / `→` | 在可见结果中切换，确保卡片滚入可见区域，不改当前内容 |
| 单击卡片 | 只选择，不自动打开浮层 |
| 卡片中的 `Space` | 打开/收起内容浮层；搜索框内空格保持输入 |
| 预览图标 | 为鼠标用户打开所选卡片预览 |
| `⌘Y` | 从搜索等上下文唤起所选项预览；无匹配项不打开空浮层 |
| 卡片中的 `Enter` | 取用该保存项，不确认其他未采用草稿 |
| 双击卡片 | 取用该卡片保存项，与浮层草稿确认分开 |
| 浮层中的 `Enter` | 取用当前可见内容：原文对照取用原文，结果视图确认派生结果；处理中不取用 |
| 按钮中的 `Enter` / `Space` | 执行按钮自身动作，不被全局取用或预览逻辑截走 |
| `⌃⌘C` | 原生守卫运行时在来源应用执行保护复制；网页中仅为显式模拟 |

预览使用非模态 dialog，并提供无障碍名称。背景卡片仍是可操作上下文，
不宣称 `aria-modal` 却允许与背景交互。卡片列表使用水平列表语义与受控焦点，
不让键盘用户逐张 Tab 穿过整个历史。切换主题不抢走或重置业务状态。

`Esc` 每次只处理最上层：

1. 图片放大层关闭，焦点返回内容预览里的入口。
2. 内容浮层关闭，同时放弃未采用草稿、取消处理并使迟到回调失效；保留搜索和选择，回焦选中卡片。
3. 主面板仍有搜索词时清空搜索，输入框继续展开。
4. 搜索输入为空但仍展开时收起搜索，焦点返回所选卡片。
5. 搜索已收起且没有预览层时关闭面板。

收起内容浮层不会提交草稿；历史中的 `Enter` 永远以保存项为准。
更换记录、搜索筛掉所选项、关闭面板都取消旧任务与草稿，防止结果串到另一记录。
快捷键在输入法组合输入时不抢占；Space 和预览组合键不因长按重复闪开闪关。
网页按键只在网页范围内生效，不替代系统全局快捷键验证。

## 七个核心状态

| 状态 | 展示 | 行为 |
|---|---|---|
| 历史 | 圆形搜索/预览按钮、横向正方形卡片、底部开关与键提示 | 初始聚焦卡片；选择不写当前内容，不自动预览 |
| 搜索 | 点击或 `⌘F` 展开输入；同一区域筛选卡片，空结果给出反馈 | 支持内容、类型、来源；选择失效时关闭浮层并高亮首个匹配项，不改变剪贴板 |
| 预览 | 独立浮层，上方内容、下方元信息与相关操作 | Space/预览图标/⌘Y 唤起；Esc 关闭回焦卡片 |
| 处理入口 | JSON 底部格式化图标 | 只列当前类型可用操作；文本与链接无空工具栏 |
| 处理中 | 具体处理状态与取消入口 | 当前内容不变；可取消；失败留在上下文，不生成空项 |
| 结果 | 结果正文、草稿标记、对比/放弃与范围；继承说明在 tooltip | Enter 确认才新增结果；原文保留；关浮层放弃 |
| 未生效 | 开关旁“已关闭”，受限范围行暖色“仅限文本编辑 · 未生效”；解释在 tooltip | 无独立大警告条，不另建页面，不移除范围 |

取用遵循所见即所得：查看原文时，浮层提示“取用原文”，回车取用保存原文并放弃未采用草稿；
返回结果视图时提示“取用结果”，回车确认派生结果。切换对照本身不改变当前剪贴板。
格式化不会自动写回，原文预览必须忠实于保存内容。

## 三条完整流程

### 普通找回

1. 用户连续普通复制多段内容。
2. 唤起面板，焦点在所选卡片；可直接浏览，或点击搜索 / 按 `⌘F` 展开输入。
3. 单击卡片，或用 `←` / `→` 选择；从搜索按 `↓` 回到所选或首张可见卡片。
4. 已能识别内容时直接 `Enter` 取用；需要完整内容时按 `Space` 打开预览，再取用。
5. 写入成功后收起；失败保留面板并说明失败，不显示成功反馈。
6. 用户在目标输入位置自行 `⌘V`。

打开面板前的应用只属于焦点恢复上下文，不是未来固定粘贴目标。
网页只更新演示内存状态，不能把该成功反馈当成系统剪贴板写入已成功。

### `⌃⌘C` 来源限定复制

1. 守卫已开启时，用户在来源应用选中文字，按 `⌃⌘C`。
2. 执行复制并等待新内容确认；不能立即把旧剪贴板标成受限。
3. 确认后保存来源范围，短暂提示“已复制 · 仅限文本编辑”，不自动打开面板。
4. 在来源应用按标准 `⌘V` 正常使用；到其他应用按标准 `⌘V`，阻止本次按键并短暂说明。
5. 从历史重新取用或增强这条内容时仍继承同一范围。

待确认时说明“正在确认保护复制…”，跨应用粘贴暂时阻止并提示尚未就绪。
不能把来源应用内粘贴成功误作保护已确认。失败时说明保护复制未完成，
不声称当前内容已经受限。下一次成功普通复制产生不带该限制的新内容，旧历史范围保留；
普通复制失败不能解除当前内容的限制。

守卫未开启时，当前机制不接管 `⌃⌘C`。引导应写“开启防误贴后可用”，
不能承诺这时会复制或弹出快捷键反馈。网页演示不接管真实快捷键。

### 增强并继承范围

1. 选择 JSON 卡片，显式打开浮层；上方原文，下方字符数、范围与格式化图标。
2. 点击格式化，当前内容不变。
3. 成功后显示草稿；受限结果仍显示“仅限文本编辑”，继承原文的说明只放在 tooltip。
   守卫关闭时范围行显示暖色“仅限文本编辑 · 未生效”，不另外增加警告条。
4. 用户可对照原文、放弃，或在结果视图中按 `Enter` 确认草稿；原文对照视图的回车取用原文。关闭浮层也会放弃未采用结果。
5. 确认时校验原范围与草稿有效性；成功写入后结果独立入历史、原文保留。
6. 用户自行 `⌘V`；结果按继承范围接受标准键盘检查。

| 分支 | 处理 |
|---|---|
| 取消、关浮层或换卡 | 丢弃草稿并使迟到回调失效；当前内容与原项不变 |
| 处理失败 | 说明原因及当前内容未改变，不生成空项 |
| 处理中发生新复制 | 新复制成为当前；处理完成仍只是草稿 |
| 草稿存在时当前内容已变 | 提示“剪贴板已有新内容，取用将替换它”，由明确取用决定是否覆盖 |
| 原范围在处理中变化 | 拒绝旧草稿确认，要求重新处理 |
| 确认写入失败 | 保留结果供检查或重试，不收起、不标记成功 |

当前本地增强只有 JSON 格式化。图片提供预览和放大，没有 OCR、压缩、去背景。
AI 尚未接入，不展示可执行的翻译、改写、总结，也不制造 AI 结果。
以后接入时仍采用处理、草稿、明确确认的流程；首次联网前说明服务和本次发送范围。

## 防误贴状态

左下角是直接 toggle，开启盾牌勾、关闭斜线盾牌，轨道颜色和滑块位置一起变化。
无需先打开状态浮层。关闭时开关旁仅显示“已关闭”。来源小锁仍显示记录范围，
但是否有效由实际守卫状态决定；关闭后的范围行使用暖色“仅限文本编辑 · 未生效”，
详细说明放在 tooltip，取消独立的大警告条。派生内容的继承说明仅在 tooltip 中显示，
来源与范围的继承逻辑保持不变。

| 实际状态 | 说明与入口 |
|---|---|
| 正常运行 | 键盘防误贴已开启；开关可直接关闭 |
| 未开启或主动关闭 | 开关旁“已关闭”；受限范围行“仅限文本编辑 · 未生效”，暖色文字及 tooltip 说明；开关可开启 |
| 缺少权限 | 说明需要辅助功能权限，提供前往设置入口 |
| 运行失效 | 说明已中断、范围暂不生效，提供恢复入口 |
| 守卫未运行时取用受限项 | 保留范围并说明当前未生效，不自动移除范围或禁止浏览 |

已授权、已请求开启都不能单独表示已开启，应以实际运行状态为准。
失败与并发内容变化保留必要文字；范围未生效用可见短语表达，原因与继承关系放在 tooltip。
精简不影响运行状态、错误恢复或范围规则，不让用户仅凭颜色判断保护是否有效。
网页只模拟开启/关闭，权限健康状态仍需正式原生实现。

## 次级功能

记录删除、范围调整等低频操作进入记录溢出菜单；设置和批量清空不进入高频取用路径。
菜单栏承担打开面板、暂停记录、设置、退出和状态。暂停普通历史记录与停止防误贴分开表达；
暂停监听时，明确触发的保护复制仍记录。从历史移除不应隐式解除当前剪贴板范围。

首版不扩展项目库、AI 聊天页、自动多内容总结或跨应用工作流编排。
应用范围编辑与真实应用选择器完成前不显示为已可用能力。

## 原生实现映射与边界

| 行为 | 已有证据或能力 | 仍需落地或验证 |
|---|---|---|
| 菜单栏与唤起 | MyGo `NewTray`、`GlobalShortcut.Register`、`WindowOptions.Panel` | 最终卡片/浮层结构、唤起键、前台焦点及光标返回 |
| 搜索与预览 | 原生验证覆盖搜索与基础预览；网页展示卡片与浮层方向 | 正式横向卡片、键盘焦点、浮层定位、来源及类型展示 |
| 取用写回 | MyGo 剪贴板读写、`Flush`，Unicode 与富文本已验证 | 最终成功/失败反馈、去重、并发新复制同步 |
| 本地增强 | 原生验证曾覆盖清理空白、JSON 格式化、草稿确认和原文保留 | 当前只保留 JSON 入口；落实浮层、取消/回焦与迟到结果处理 |
| 来源限定复制 | 事件 tap、版本校验、来源身份及范围绑定；TextEdit 核心路径实测通过 | 其他应用、复制失败、快速切换及正式反馈 |
| 标准键盘防误贴 | 部分真实按键的选择性放行/阻止已验证 | 守卫健康、权限失效、恢复流程 |
| 范围继承 | 历史取用和增强继承、过期范围草稿拒绝已验证 | 最终范围文案、编辑入口及独立生命周期 |
| 历史管理 | 当前以内存历史为主 | 持久化、保留设置、删除与清空 |
| 图片 | 底层 PNG 剪贴板读写已验证 | 原生图片历史采集、缩略图、预览、取用和保护复制逐项实现 |
| 深浅外观 | 用户确认玻璃与扁平控件，网页支持主题偏好 | 原生材质、系统设置、复杂背景对比及透明度回退 |
| AI | 仅 provider 接口，未配置真实服务 | 接入、联网说明、失败与取消，随后纳入草稿流程 |

本轮仅修改网页原型，不替换已验证的原生应用，不重新申请系统授权。
[设计验收](prototype-qa/final-design-qa.md) 只证明其中记录的网页检查。

当前承诺是应用级的**标准 `⌘V` 键盘防误贴**。菜单/右键粘贴、后台读取剪贴板、
同一应用内不同联系人或浏览器标签页不属于当前保证范围。匹配样式粘贴等其他快捷键
需要独立实测，不能由标准 `⌘V` 的通过推断全部通过。
来源由前台应用与新剪贴板版本尽力关联，公共剪贴板不提供可信写入者证明。
界面使用“应用范围”“键盘防误贴”，不承诺其他应用绝对无法获取内容。

优先级为状态可信，其次落实卡片、浮层与焦点动线，最后逐项补历史持久化、应用选择器和 AI。
未确认不报保护成功，失效不显示有效，未采用草稿不覆盖当前内容。
