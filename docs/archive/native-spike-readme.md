# Copiggy / MyGo 原生面板

这是 macOS 本地集成版本：管理真实剪贴板历史、按来源应用防误贴、预览并增强内容。**应用界面由 MyGo `ui.View` 原生渲染。** 主托盘使用系统玻璃，正方形内容卡片的预览使用系统 `NSPopover`。只有链接预览中的网页正文由系统 `WKWebView` 显示，工具栏和加载/失败状态仍为 Native UI，不使用 Web 前端实现应用。

应用只在用户确认取用时写入系统剪贴板，随后由用户自行 `⌘V`。它不会自动粘贴或向其他应用发送内容。

## 运行

```sh
cd experiments/mygo-clipboard
sh run.sh run
```

首次构建使用 Go 1.27.1，将固定版本依赖放在项目 `.cache/` 中。运行不需要 Bun、Node 或 cgo。

| 命令 | 用途 |
| --- | --- |
| `sh run.sh run` / `sh run.sh panel` | 启动当前原生面板，失焦自动收起 |
| `sh run.sh bundle` | 构建 `build/Copiggy Spike.app`，使用本地 ad-hoc 签名 |
| `sh run.sh test` | 运行内容模型、事务、保护规则与原生辅助层测试 |
| `sh run.sh probe` | 只读权限探测，不读取剪贴板内容，不弹授权提示 |
| `sh run.sh self-test` | 使用合成数据验证剪贴板读写及旧诊断窗口；尝试恢复原剪贴板 |
| `sh run.sh build` 后运行 `build/copiggy-spike --inspect` | 在普通窗口中打开相同的 Native UI，供桌面工具检查 |
| `sh run.sh build` 后运行 `build/copiggy-spike --diagnostic` | 打开保留的旧诊断界面 |

`self-test` 需要正常桌面会话，会短暂改写剪贴板；测试期间不要同时复制其他内容。恢复前会核对版本，发现新的外部复制时保留新内容，不覆盖它。旧诊断界面的示例记录不会加载到默认原生面板。

`--inspect` 与默认面板使用相同的原生界面和剪贴板逻辑，只改变窗口形式以便工具检查；默认仍是无标题栏、失焦收起的面板。

打包路径仍为 `build/Copiggy Spike.app`，bundle ID 仍为 `dev.copiggy.spike`。

## 系统玻璃与预览

- macOS 26 上，主托盘将 MyGo 原生绘制层放入 `NSGlassEffectView`；不支持该类的系统回退到 `NSVisualEffectView`。本轮 macOS 26.5 实机日志已确认使用 `liquid-glass`，旧系统回退尚未实机验证。
- 预览由 MyGo `NewFlyout(Popover: true)` 承载原生 `ui.View`，材质、连续箭头、阴影和屏幕边缘翻转由 `NSPopover` 决定。箭头指向选中卡片，间距及边缘翻转不再手工固定。
- 点击外部关闭预览会销毁该浮层；主动收起可复用。关闭时取消未确认草稿，返回卡片操作。深浅外观通过局部系统外观与内容配色切换。
- 预览操作统一放在顶部，底部只保留尺寸、字数与保护范围；无底部取用/收起提示。材质主题直接同步到 `NSPopover.appearance`。悬停提示和操作结果以简短文字暂时显示在 macOS 菜单栏图标旁，不再创建独立提示框。
- 卡片滚动视口贯穿托盘宽度，22px 留白在内容首尾，而非固定在视口左右；图片时间、尺寸和图钉使用小块灰色毛玻璃衬底，背景真实模糊，前景文字保持清晰。
- 内容与控件统一使用 macOS 系统无衬线字体，中文、日文及 emoji 由系统按内容回退，JSON 使用系统等宽字体。正文采用常规字重，短标题用中等字重，并统一时间与尺寸的数字宽度。
- 链接通过空格或 `⌘Y` 打开真实网页预览；浮层提供刷新、停止、返回和浏览器打开。网页内点击或输入时，键盘交给系统 WebKit，可随时使用顶部关闭按钮返回卡片。

单个主窗口截图可能裁掉窗口上方的独立预览浮层，应结合桌面画面或其辅助功能节点检查。详见[系统玻璃接入记录](system-glass-integration-2026-10-21.md)。

## 真实内容流程

1. 启动后恢复本机 Pin 记录，并开始记录新的复制；不读取启动前的剪贴板，不加载示例。
2. 普通 `⌘C` 形成无应用限制的历史项。文本、JSON、链接和图片使用不同卡片，右上角显示来源应用图标。完全相同的保存内容且保护范围相同时，更新旧记录时间并移到最前，保留原 ID 与来源；不同保护范围不合并。
3. 打开面板，选择卡片；空格或 `⌘Y` 打开浮层。浏览和搜索不改变当前剪贴板。
4. 回车或双击卡片取用内容，面板收起；用户回目标应用自行 `⌘V`。
5. JSON 格式化先产生本地草稿，可对照原文、放弃结果。回车或顶部草稿确认按钮才写回并生成新记录，原记录保留，来源应用范围也会继承。关闭预览、切换记录或收起面板会取消未确认草稿。

图片支持 PNG，以及 MyGo 转为 PNG 的原生 TIFF 表示；可查看尺寸、打开完整图片预览、取用原始保存的剪贴板表示。文本可同时保留其 HTML/PNG 表示。链接卡片显示地址信息，并异步读取网站 HTML 中的 icon；失败时尝试 favicon.ico，再回退通用图标。只对未限定应用的公开链接请求网站首页与图标，不发送复制 URL 的路径、参数、片段或浏览器凭据。取用仍然是复制地址。完全透明的图片不入库；HTML 配合透明/1×1 占位图时使用正文预览，保留原始剪贴板表示。合法的不透明 1×1 图片仍可记录。

与上述后台图标请求不同，实际网页仅在用户主动打开链接预览后加载完整 HTTP/HTTPS 地址，包含其路径和参数。预览使用 Copiggy 内 WebKit 自己的正常持久网站数据，不读取外部浏览器会话；不向页面开放应用 Go bindings，不自动下载或弹出新窗口。部分网站需要在预览中重新登录，也可点顶部图标使用默认浏览器打开。关闭预览会销毁当前网页视图，重新打开重新加载；原始保存链接及保护范围不因网页内导航而改变。

清理空白引擎也已实现，当前可从旧诊断界面生成和确认草稿；默认原生面板的纯文本预览不放置常驻操作区。

| 操作 | 快捷键 / 控件 |
| --- | --- |
| 唤起或收起面板 | `⌃⌥⇧Space`，或点击菜单栏剪贴板图标 |
| 复制并限定来源应用 | 防误贴开启后，在来源应用按 `⌃⌘C` |

| 取用选中内容 / 当前草稿结果 | `↵`；卡片支持双击取用 |
| 逐层返回 | `Esc`：退出图片放大、关闭预览、清空搜索、收起搜索框、关闭面板 |
| 防误贴 | 面板左下角盾牌 toggle，或菜单栏右键菜单 |

## ⌃⌘C 防误贴

启动会尝试使用已有授权开启守卫；失败时显示关闭状态，不自动弹出系统权限请求。点击盾牌才主动请求辅助功能授权，授权后需要再次点击重试。界面根据实际原生监听状态显示开关；应用范围在守卫关闭时标记为“未生效”。

守卫开启后，`⌃⌘C` 将该次按键交给来源应用执行普通复制，等待新的、可读取的剪贴板版本，再绑定来源应用 bundle ID。成功后菜单栏短暂显示“仅限 来源应用”，来源图标右上角显示小锁；守卫开启时菜单栏剪贴板图标带盾牌。没有选区、来源切换、期限或版本不匹配时不会把旧内容冒充为本次受限复制。等待最多 2 秒，等待期间跨应用快捷键粘贴暂时阻止。

`⌃⌘C` 是明确的记录动作，即使暂停普通历史记录也会保存这次保护复制。普通 `⌘C` 不继承上一条内容的范围；原来的受限记录仍保留在历史中。取用历史项及确认增强结果时，限制绑定到该次成功写入的版本，使用独立写入标记核对归属，避免把同值文本或其他写入者的版本误认作自己的写入。

**覆盖范围是标准 `⌘V` 和 `⌘⌥⇧V`。** 菜单粘贴、右键粘贴、自定义快捷键、后台读取剪贴板，以及同一应用里的错误联系人不在保护范围。退出应用、撤销权限或监听失效后，这一拦截机制不再生效。它用于防误操作，不是系统级内容隔离。

本地 ad-hoc 签名随二进制变化，重新构建后可能需要刷新辅助功能授权。应用路径、bundle ID 与实际签名必须匹配；系统设置显示旧条目开启，并不能证明新构建已获授权。

## 数据与资源边界

- 普通历史只保存在当前进程内，最多 100 条；退出后丢失。Pin 单独最多 100 条，保存到 `~/Library/Application Support/Copiggy/pinned.json`，文件权限 0600，原子替换；原始表示、来源和保护范围一并保留。所有记录仍受 64 MiB 总内容预算约束。取消 Pin 后恢复普通历史保留规则；删除记录不清空系统剪贴板或解除其原生保护。
- 默认英文，菜单支持简体中文、繁体中文和日语，偏好保存在同目录 `preferences.json`。
- 每条所有已保留表示合计最多 16 MiB；文本最多 1 MiB；图片最多 2400 万像素，并校验 PNG 数据。
- 会话保存的剪贴板表示合计最多 64 MiB，超过时淘汰最旧记录；已解码图片另设最多 8 张的缓存，并随历史淘汰清理。64 MiB 是保存内容预算，不是整个进程的内存上限。
- 普通历史通过剪贴板版本轮询获取，极短间隔的多次复制可能被合并观测。普通复制的来源是当时前台应用的尽力识别，不能作为可信写入者证明。
- 保护复制额外核对来源、请求 ID、期限与版本，但系统剪贴板没有可靠的写入者身份，后台竞争下仍有边界。
- 图片字节、来源应用图标与增强在本机处理。网站图标有独立的有界网络缓存，失败不阻塞面板。当前没有云端 AI 请求，也没有历史上传。
