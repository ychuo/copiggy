# Copiggy native integration

- The application is the root Go module `copiggy`: `main.go` calls `internal/app.Run`; `internal/app` owns composition, lifecycle and serialized command dispatch; `internal/app/nativeui` owns native views and transient UI state; `internal/clipboard` owns history/capture/copy transactions; `internal/clipmodel` owns pure records, recognition and conversion rules; `internal/contentactions` derives explicit external-action targets; `internal/settings` owns preferences; `internal/storage` owns compatible JSON repositories and atomic writes; `internal/linkicons` owns restricted-origin icon retrieval; `internal/linkmetadata` owns bounded copied-HTML and public-page metadata retrieval; `internal/macos/{pasteboard,guard,appkit}` owns platform adapters. `resources` embeds runtime artwork, `mygo.json` owns bundle metadata and icon configuration, and `scripts` owns build/check/package commands. Do not recreate the retired `experiments` tree or its web prototype, diagnostic UI or synthetic clipboard self-test. Keep obsolete design exports and manual test checklists out of the repository; preserve runtime artwork, automated tests and current maintenance documentation.
- The user explicitly requires MyGo **Native UI** (`Content: ui.View(...)`) for the application, not an embedded web frontend. The web prototype is a visual reference only. The later request to preview actual linked pages permits a system WKWebView solely for webpage content inside the native NSPopover; its toolbar, loading/error states and surrounding UI remain Native UI. Create and load the webpage view only when the user opens its preview, never during history capture. The subsequent request for ordinary-link covers also permits bounded HTTP metadata/image retrieval for visible or near-visible unrestricted public link cards, including the saved path/query but excluding its fragment; no browser credentials, referrer or scripts. `internal/linkmetadata` owns that retrieval and copied-HTML parsing. Recheck saved protection before requests and completion; cancel pending work on hide/quit or record invalidation, and keep a bounded memory cache. Do not expose app bindings to remote pages or permit automatic downloads/new windows. MyGo currently uses its default persistent WebKit data store; do not describe this as private browsing.
- Build the approved 188px square content cards, circular expanding search, native source-app icons with lock badge, guard toggle, light/dark modes, no titlebar or internal divider lines. There is no eye button; Space/Cmd+Y opens preview. The tray uses NSGlassEffectView with the MyGo surface as contentView, falling back to NSVisualEffectView on older systems. Preview uses a system NSPopover with native MyGo content: compact top action toolbar, content, then metadata; no bottom use/close keyboard hints. Let AppKit own its continuous arrow, spacing and screen-edge placement rather than drawing a separate pointer. Match the NSPopover's own appearance to the selected theme, and keep the native surface transparent. Do not create tooltip/toast windows. Only protection updates and actionable errors appear temporarily beside the macOS menu-bar icon, whose shield badge follows the live guard state; hover and routine successes stay quiet.
- Exact repeated clipboard representations with the same allowed-app set refresh the existing record's time and move it to the front, retaining its ID and original provenance. Never merge records with different protection scopes. The compact tray is 296px tall and 80% of the active display work-area width: 30px search control, 24px guard toggle and 20px keycaps. Pause/resume recording and light/dark selection belong in the menu-bar right-click menu, not the panel. Hide the history scrollbar while retaining scrolling; keep 22px padding only at the beginning and end of the content, with a full-width viewport so partial cards can reach both edges in the middle. Use brief native search/scroll/control animation that honors Reduce Motion. Toolbar mouse clicks preserve history/search focus; search keeps Left/Right for its caret. Image metadata uses small neutral-gray frosted-glass backplates with actual backdrop blur and crisp contrasting ink, never full-width black scrims or altered image pixels. UI icons use softer gray while source application icons preserve their original appearance, and the selection stroke must coincide with the card's outer contour.
- The app manages clipboard contents; it never simulates paste. Enter/double click copies the selected item and hides the panel; the user presses Cmd+V. Opening preview alone keeps exact-original copying. Explicit JSON Format, color HEX/RGB/HSL, phone Dialing, or timestamp s/ms selection chooses a transient copy variant; changing that choice alone never writes. Explicit copy derives the result from the trusted record or validated draft and inherits its saved allowed apps, without editing the source or adding a history record. Local/UTC, Reveal and zoom remain presentation-only. Closing or navigating resets format choices. No paste or redundant primary CTA.
- Finder file references use the same presentation as their full path text: one path uses the existing file-path card/preview, and multiple paths use ordinary multiline text. Copying such a record from Copiggy always writes path text with its saved protection scope; there is no Files/Paths mode or native file-reference write. Capture and preview remain read-only, so direct Finder Cmd+C/Cmd+V file pasting is unaffected. Retain captured representations for history integrity and migrate older file cards compatibly.
- Phone recognition uses general numbering metadata and explicit or system regional context. Do not introduce country-specific priority overrides to accommodate an individual example; UI language must not select a phone region. Phone preview may use embedded geocoding to show numbering-prefix areas, with a localized description or English fallback and no duplicate country-only result; this never means live location and never runs during capture.
- Use actual clipboard records, no seed examples or synthetic self-test modes in the application. Fixtures belong in tests.
- Protected Ctrl+Cmd+C and native paste guards remain revision-bound, enforce the existing source and request checks, and inherit allowed apps into enhancement results. Never trust UI-provided content/policies. Report guard state from the live native tap.
- Enhancements remain local JSON formatting/whitespace operations with preview, explicit confirmation and cancel. Return or Copy result confirms the visible draft; Copy original retains the exact source. Derived clipboard output is not saved as another history item. No external AI calls or silent upload. Keep original and scope; cancel stale work when navigating/hiding. Timestamp conversion to seconds truncates subsecond digits only in the copied variant; the original milliseconds stay saved.
- The official app is `build/Copiggy.app`, with bundle identifier `dev.copiggy`, display name `Copiggy` and executable `copiggy`. Use these names consistently in code and scripts. Rebuilding or relocating may still need user-authenticated macOS permission refresh. Do not manipulate TCC databases.
- The user now performs visual and interaction verification manually. After changes, build and restart the app; do not run automated desktop/clipboard scenarios, generate test records, take verification screenshots, or change permissions unless the user explicitly requests it.
- Run `./scripts/check.sh` for formatting, default in-memory tests, vet and a production-mode build. Native tests that inspect real foreground/clipboard state require the explicit `integration` build tag and must not be run without user authorization. `./scripts/package.sh` builds and signs the bundle; `./scripts/run.sh` builds it and starts it. Preserve MyGo's production linker flag so remote localhost previews do not receive development-mode trust.

- Default product copy and source keys are concise English. Keep menus, status, hints, errors and accessibility labels in the four-language catalog (English, Simplified Chinese, Traditional Chinese, Japanese); save language, explicit light/dark preferences, history retention, recording pause and desired Paste Guard enablement together locally and restore them before the first panel render. The desired guard preference must remain distinct from the actual live native listener and its revision-bound policy; never restore stale clipboard authority. Legacy language-only preferences retain the system appearance until the user selects a theme. Chinese/Japanese belong in translation resources and intentional content fixtures, not hardcoded runtime strings. Translate UI summaries rather than exposing raw system or file errors; log technical details in English. User clipboard content and actual application names are never translated.
- Typography uses bundled Inter for Latin text, Noto Sans SC / TC for Simplified / Traditional Chinese and Noto Sans JP for Japanese across card prose/link titles, plain-text preview and compact controls/metadata. Register complete Regular 400 and Medium 500 faces within the application before rendering; never install fonts system-wide or download them at runtime. UI language selects its CJK family; clipboard language/script hints remain independent of the menu language, with a deterministic fallback for ambiguous Han-only text and system fallback for emoji/unsupported scripts. Keep JSON, credentials and alignment-dependent counters in `monospace`. Use regular 400 body, medium 500 short titles, 15/18px card text and 17px preview text; avoid making all copied content bold. Time/dimension numerals use `tnum`. Native NSMenu text, MapKit labels and linked webpage content retain system/site typography. Keep font provenance and OFL licenses in `resources/fonts/`, and retain the licenses when packaging while removing duplicate embedded font assets.
- Pin/unpin is available on cards, in preview, and with Cmd+P. The top pin button filters history. All history persists locally with exact saved representations, source, timestamps and protection policy. Ordinary history expires after the chosen 1, 7 or 30 days (default 30), or never by age; pins are exempt from age expiry. The existing 100 ordinary / 100 pinned item and shared 64 MiB bounds still apply. Legacy pinned.json migrates to history.json once; never resurrect legacy pins after a successful migration. Never select or write the clipboard when pinning/restoring. Unpinning the active preview from the pin filter cancels its draft.
- Cmd+Backspace deletes the selected history record except while search owns input. Preview also provides Delete. Deleting a current history record must leave the system clipboard and native revision-bound guard untouched.
- The menu-bar settings menu uses system NSMenu styling: SF Symbol icons on the left, real native key equivalents on the right, and groups for clipboard controls, appearance/language and quit. Build it from the same localized MyGo menu model; dispatch the selected action after tracking ends. Never append shortcut text to labels or register a duplicate global shortcut just for display. Menu-bar text is limited to Paste Guard/protected-copy updates and actionable errors. Do not display hover hints or routine copy, pin, delete, theme, language, recording or retention success messages.
- Website icons are fetched asynchronously only for unrestricted public links. Prefer copied/root HTML icon, fall back to favicon.ico then a generic icon. Never send copied path/query/fragment or browser credentials; respect cache, timeout and size limits. Fully transparent image representations are ignored; HTML with a transparent or 1x1 placeholder uses text for preview while retaining exact original data.
- Link title/cover metadata is separate from website icons: visible unrestricted public cards may fetch their saved path/query, without fragments, credentials, cookies or scripts. Prefer matching copied HTML. Never fetch during capture or for private/protected destinations; validate DNS and redirects, bound requests/decodes/cache, and recheck record authority before starting and publishing. Maps and covers belong to the panel lifetime: card navigation must not restart still-useful work; hide/quit and record removal or protection changes cancel obsolete work.
- The brand uses the Little collector pig in `resources/brand/app-icon.png`: simple peach-and-coral doodle artwork with rounded warm-brown outlines. The app icon uses that image directly. Empty history has the matching blank tilted clipboard, occasional native blinks and three native content strokes aligned to its paper that reveal sequentially, pause and fade. The empty pinned list uses matching ready/pressed pin poses with a long rest between actions. Search with no results keeps its semantic icon. The monochrome menu-bar pig gains a shield/check only when the live guard is enabled. Assets live in `resources/brand/`. Keep animation quiet, schedule only its frame changes and honor Reduce Motion. Packaging compiles the exact original artwork through `resources/brand/Copiggy.icon` into Assets.car and an ICNS fallback using Xcode 26 or later; bundled launches must not override that icon with Dock.SetIcon.
